# Security Policy

## Prototype status

Doxxer Kernel is at an early research-prototype stage. It must not be used to protect sensitive production workloads. The current milestone has no user-mode isolation, storage encryption, network stack, or Secure Boot chain.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature when it is enabled. Include the affected commit, reproduction steps, impact, and any proposed mitigation.

## Supported versions

Only the latest commit on `main` is supported during the prototype phase.
